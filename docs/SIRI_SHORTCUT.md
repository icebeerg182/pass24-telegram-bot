# Siri Shortcut для заказа пропусков

Заказ пропуска голосом с iPhone, HomePod или Apple Watch через приложение **Команды** (Shortcuts).

Используется тот же сервер и аккаунт PASS24, что у Telegram-бота и навыка Алисы.

## Что нужно

- iPhone с приложением **Команды** (Shortcuts), iOS 16+
- Работающий сервис `pass24-alice` с HTTPS (см. [ALICE_SKILL.md](ALICE_SKILL.md))
- `ALICE_WEBHOOK_TOKEN` или отдельный `SIRI_WEBHOOK_TOKEN` в `.env`

URL для Shortcut (подставьте свои значения):

```
https://ВАШ-ДОМЕН/siri/pass/ВАШ_ТОКЕН?q=
```

К запросу Shortcuts допишет марку и номер, например: `...?q=мазда%20656`

## Настройка Shortcut (5 минут)

### 1. Создать команду

1. Откройте **Команды** → **+** → **Новая команда**
2. Имя: `Пропуск Кембридж` (или своё)

### 2. Добавить действия

**Шаг 1 — спросить марку и номер**

- Действие: **Спросить ввод** (*Ask for Input*)
- Вопрос: `Марка и номер?`
- Тип: **Текст**
- Включите **Диктовка** (иконка микрофона в поле ввода при тесте)

**Шаг 2 — запрос на сервер**

- Действие: **Получить содержимое URL** (*Get Contents of URL*)
- URL (одна строка, `ВАШ_ТОКЕН` — из `.env`):

  ```
  https://ВАШ-ДОМЕН/siri/pass/ВАШ_ТОКЕН?q=
  ```

- Нажмите **Показать больше**:
  - В конце URL нажмите **Выбрать переменную** → **Предоставленный ввод** (результат шага «Спросить ввод»)
  - Метод: **GET**
  - Кодировка URL: включена (по умолчанию Shortcuts кодирует кириллицу)

**Шаг 3 — озвучить ответ**

- Действие: **Произнести текст** (*Speak Text*)
- Текст: **Содержимое URL** (результат предыдущего шага)

**Шаг 4 — показать на экране** (опционально)

- Действие: **Показать уведомление** или **Показать результат**
- Текст: тот же **Содержимое URL**

### 3. Привязать к Siri

1. Нажмите **ⓘ** (Сведения о команде) вверху
2. **Добавить на экран «Домой»** — по желанию
3. **Добавить в Siri** → запишите фразу, например: **«Пропуск Кембридж»**

### 4. Проверка

Скажите:

> **«Привет, Siri, пропуск Кембридж»**

Siri запустит команду → спросит марку и номер → скажите **«мазда 656»** или **«лисян 7 8 7»**.

Должен прозвучать ответ: «Готово. Пропуск на …»

## Примеры фраз при запросе марки

| Скажите | Результат |
|---------|-----------|
| `мазда 656` | Mazda 656 |
| `мазда 6 5 6` | Mazda 656 (цифры склеиваются) |
| `лисян 7 8 7` | LiXiang 787 |
| `бмв 1 2 1` | BMW 121 |

## HomePod и Apple Watch

- **HomePod:** команда должна быть синхронизирована через тот же Apple ID (iCloud → Команды).
- **Apple Watch:** после настройки на iPhone команда появится на часах; фраза та же.

## Поделиться с семьёй

1. В **Командах** откройте команду → **ⓘ** → **Поделиться**
2. Отправьте ссылку (iCloud)
3. Получатель импортирует команду и в URL **заменит токен на свой** — или используйте общий токен (все заказывают на ваш адрес PASS24)

## Безопасность

- Токен в URL — секрет; не публикуйте команду с токеном в открытый доступ
- Отдельный токен: `SIRI_WEBHOOK_TOKEN` в `.env` (если пусто — используется `ALICE_WEBHOOK_TOKEN`)

## Устранение неполадок

| Симптом | Решение |
|---------|---------|
| Пустой ответ / ошибка сети | Проверьте HTTPS и URL в команде |
| `not found` | Неверный токен в URL |
| «Не найден госномер» | На сервере `BOT_REQUIRE_FULL_PLATE=false` для Кембриджа |
| «Пропуск уже создан» | Удалите дубликат в Telegram-боте или подождите |
| Siri не запускает команду | Перезапишите фразу в «Добавить в Siri» |

## Проверка без iPhone

```bash
curl -sG "https://ВАШ-ДОМЕН/siri/pass/ВАШ_ТОКЕН" \
  --data-urlencode "q=мазда 656"
```

Ожидается текст: `Готово. Пропуск на Mazda 656...`
