# Changelog

## [0.0.8] — 2026-09-27

### Добавлено

- Сервис `pass24-alice`: HTTP webhook для навыка Яндекс Алисы (заказ пропуска голосом без подтверждения)
- Распознавание произнесённых цифр («шесть пять шесть» → `656`)
- Документация [docs/ALICE_SKILL.md](docs/ALICE_SKILL.md): настройка приватного навыка и шаринг с друзьями
- Переменные `ALICE_WEBHOOK_TOKEN`, `ALICE_PORT`, `ALICE_SKILL_INVOCATION`, `ALICE_ALLOWED_USER_IDS`

## [0.0.7] — 2026-09-27

### Добавлено

- При `BOT_REQUIRE_FULL_PLATE=false` принимается марка + только цифры (`Mazda 100`), а также короткий/полный госномер

## [0.0.6] — 2026-09-27

### Добавлено

- Настройка `BOT_REQUIRE_FULL_PLATE`: полный госномер с регионом (`А121МР77`) или гибкий номер
- Вопрос при первой установке (`deploy/install.sh`): требует ли адрес полного номера
- Примеры в `/start` и `/help` зависят от режима

## [0.0.5] — 2026-08-16

### Добавлено

- LLM fallback для марки через Groq (`BOT_LLM_BRAND_RESOLVER`), если обычный парсер не распознал бренд; результат кэшируется в `data/brands_learned.json` и сверяется со справочником PASS24
- Алиасы: Marussia (`маруся`), Sollers (`солерс`/`соллерс`), расширенный сленг BMW (`бэха`)

## [0.0.4] — 2026-08-11

### Добавлено

- Приём ссылки Яндекс Доставки `https://dostavka.yandex.ru/route/#…`: бот читает публичный трекинг (`shared-route/info`), достаёт марку и госномер курьера и создаёт пропуск
- Нормализация длинных названий (Wheely и др.): `Mercedes-Maybach S-Класс Z223, У 061 ЕН 550` → Mercedes-Benz / У061ЕН550; отдельно `Maybach` → Maybach

## [0.0.3] — 2026-07-17

### Добавлено

- Расширенный словарь сокращений марок (~80 брендов): Peugeot, Citroen, Opel, Fiat, Alfa Romeo, Seat, Cupra, Suzuki, Infiniti, Genesis, китайские бренды (Voyah, Aito, Nio, XPeng, Belgee и др.), американские (Dodge, Cadillac, Hummer) и др.

## [0.0.2] — 2026-07-03

### Добавлено

- Интерактивные настройки в `deploy/install.sh`:
  - спрашивать тип ТС (легковой/грузовой) при заказе
  - спрашивать подтверждение перед созданием пропуска
  - кнопка выбора адреса по умолчанию (если несколько адресов)
- Переменные `BOT_ASK_VEHICLE_TYPE`, `BOT_CONFIRM_BEFORE_CREATE`, `BOT_ENABLE_ADDRESS_PICKER`
- Кнопки «Легковой» / «Грузовой» и подтверждение заказа в Telegram
- Кнопка «📍 Адрес» для смены адреса по умолчанию

## [0.0.1] — 2026-07-03

### Добавлено

- Telegram-бот для заказа автомобильных пропусков PASS24 (mobile API жителя)
- Гибкий парсер марки и госномера (любой порядок, пробелы, две строки)
- Словарь сокращений марок и подсказки при ошибке
- Управление доступом: `/allow`, `/deny`, временное открытие `/open 12|24|48`, `/close`
- Кнопки «Изменить» и «Удалить» под созданным пропуском
- Docker-образ и `docker-compose.yml`
- Интерактивный установщик `deploy/install.sh` с проверкой кредов
- `deploy/validate_env.py` — проверка `.env` (Telegram + PASS24)
